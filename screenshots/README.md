# Scenario 02 Screenshots

This directory preserves the original engineering/operator screenshot sets that were already part of the Scenario 02 repository.

Role-closeout evidence is intentionally stored with the role that generated it:

- SOC: [`../soc/evidence/`](../soc/evidence/)
- Incident Response: [`../ir/evidence/`](../ir/evidence/)
- Operator: [`attacker/`](attacker/)
- Detection Engineering: [`detection-engineering/`](detection-engineering/)
- ML Engineering: [`ml/`](ml/)

This avoids turning one screenshot directory into an unstructured dump while preserving clear ownership and relative links from each flagship document.

## Public evidence rule

Keep screenshots that answer a technical question or prove a transition. Preserve troubleshooting/progress images in source archives when useful, but do not promote them into the main narrative unless the root cause teaches a reusable lesson.
