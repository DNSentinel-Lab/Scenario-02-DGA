# 🖼️ Scenario 02 Screenshots

This directory preserves the original engineering/operator screenshot sets that were already part of the Scenario 02 repository. Role-closeout evidence remains stored with the role that generated it so the repository does not collapse all proof into one unstructured image dump.

## 🗂️ Evidence Ownership

| Role / workspace | Location | What it preserves |
|---|---|---|
| 🔎 SOC Analyst | [`../soc/evidence/`](../soc/evidence/) | E01–E13 investigation evidence |
| 🛡️ Incident Response | [`../ir/evidence/`](../ir/evidence/) | E01–E21 validation, containment, verification and reset evidence |
| 🧬 Operator / Project Lead | [`attacker/`](attacker/) | Official execution command, completion and ground truth |
| 🚦 Detection Engineering | [`detection-engineering/`](detection-engineering/) | Baseline, detection, dashboard, alert and AI integration validation |
| 🧠 ML Engineering | [`ml/`](ml/) | Feature engineering, training, scoring and HEC write-back evidence |

## 📌 Public Evidence Rule

Keep screenshots that answer a technical question or prove a transition. Preserve troubleshooting/progress images in source archives when useful, but do not promote them into the main narrative unless the root cause teaches a reusable lesson.

> [!IMPORTANT]
> Screenshots support reasoning; they do not replace it. Each flagship document explains what was tested, what the image proves, and what remains outside the evidence boundary.
